# PS4 Linux (homebrew PKG)

Standalone **Library** app for GoldHEN: loads **ps4-linux-loader** from **`/data/payloads/`** and boots **`/data/linux/boot/`**.

## Build (Mac)

```bash
swift tools/ps4-linux-launcher-build.swift
```

Output: `linux-loader/PS4-Linux-v*.pkg`

See repository [docs/PS4-LINUX-LOADER-PKG.md](../docs/PS4-LINUX-LOADER-PKG.md).
